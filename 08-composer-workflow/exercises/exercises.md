# Module 08 — Exercises

1. Cloud Composer vs Cloud Workflows vs Cloud Scheduler — pick the right tool for a scenario.
2. Write a DAG with a data dependency: extract (Dataflow) then load (BigQuery).
3. What is `catchup` and when should it be `False`?
4. How do you make a scheduled report DAG idempotent?
5. What is Eventarc and how does it differ from Cloud Scheduler triggers?
6. How would you alert when a DAG fails more than once in 10 minutes?
7. What operator do you use to run a parameterized Dataflow job from Airflow?
8. Why might you choose serverless Workflows over Composer?
9. What are Airflow Variables and how do you store secrets safely in Composer?
10. Describe the DAG run lifecycle: queued → running → success/failed.
