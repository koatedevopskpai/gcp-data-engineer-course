# Lab 09.1 — Connect Looker Studio to BigQuery

## Objectives
- Create a Looker Studio data source from `cymbal_warehouse.taxi_trips`.

## Steps
1. Open https://lookerstudio.google.com
2. Click **+ Create → Data source**.
3. Choose **BigQuery** → your project → dataset `cymbal_warehouse` → table `taxi_trips`.
4. Click **Connect**, review fields, then **Create report**.

## Exam notes
- Looker Studio is **free**; Looker (the product) is a separate enterprise BI tool.
- The exam tests **Looker/LookML** concepts — see the `lookml/` reference files.
- Use **BI Engine** (Module 04) to speed up Looker Studio dashboards.
