# Module 12 — Exam Preparation

Everything for the final push: study plan, 50 practice questions with
explanations, 2 full mock exams, case studies, cheat sheets, glossary, and
exam-day tips.

## Contents

| File | Purpose |
|---|---|
| `study-plan.md` | Week-by-week prep schedule |
| `practice-questions-50.md` | 50 questions **with explanations** |
| `mock-exam-1.md` / `mock-exam-2.md` | Timed full-length mocks |
| `case-studies.md` | Cymbal Retail + others (architecture answers) |
| `cheat-sheets.md` | Master decision tables (which service, when) |
| `glossary.md` | Exam terminology |
| `exam-tips.md` | Exam-day strategy, question patterns |

## How to use

1. Read `study-plan.md` and set a target date.
2. Take **mock-exam-1** cold → note weak domains.
3. Work modules for the weak domains, then `practice-questions-50.md`.
4. Take **mock-exam-2** timed; review `cheat-sheets.md` daily.
5. The night before: `exam-tips.md` + `glossary.md`.

## Coverage notes

- Domain weightings follow the current Google Cloud Professional Data
  Engineer guide; Module 13 (ML) is included because it maps to the
  15–20% ML-modeling domain.
- Questions are designed to be "two answers look right" — the explanations
  cover *why* the distractor is wrong.
