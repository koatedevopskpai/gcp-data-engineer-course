# 4-Week Study Plan (Google Professional Data Engineer)

Exam: 2 hours, ~50 questions (may include case studies). Pass at least ~70%.
Workload: 1–2 hours/day + 4–6 hours on weekends.

## Week 1 — Foundations (Modules 1–3)
- Day 1–2: Module 1 (account, IAM, gcloud, budgets).
- Day 3–4: Module 2 (Cloud Storage classes, lifecycle, CMEK).
- Day 5–7: Module 3 (BigQuery, partitioning, clustering, external tables, slots).
- **Checkpoint:** complete Module 1–3 exercises; run Lab 2.1, 3.1–3.3.
- **Cost rule:** create the budget (Lab 1.5) before anything else.

## Week 2 — Processing (Modules 4–6)
- Day 8–9: Module 4 (nested data, windows, UDFs, authorized views, Dataform).
- Day 10–11: Module 5 (Beam, batch→streaming, windows/triggers, Flex templates).
- Day 12–14: Module 6 (Dataproc, PySpark, workflow templates).
- **Checkpoint:** run Beam ETL + streaming labs; submit one PySpark job;
  answer the "Dataflow vs Dataproc" compare questions.

## Week 3 — Streaming & Orchestration (Modules 7–9)
- Day 15–16: Module 7 (Pub/Sub topics, DLQ, exactly-once, ordering, snapshots).
- Day 17–18: Module 8 (Composer DAGs, Workflows, Scheduler, Eventarc).
- Day 19–21: Module 9 (Looker Studio dashboard + LookML concepts).
- **Checkpoint:** publish/subscribe end-to-end; write one DAG; build a dashboard.

## Week 4 — ML, Governance & Full Mock Exams (Modules 10, 13, 12)
- Day 22–23: Module 10 (policy tags, Data Catalog, VPC-SC, DLP, audit logs).
- Day 24–25: Module 13 (BigQuery ML + Vertex AI — closes the ML domain).
- Day 26: Review cheat sheets + glossary; re-read COURSE-MASTER.md errata.
- Day 27: **Mock Exam 1** (timed 90 min, no notes).
- Day 28: **Mock Exam 2** (timed) + review every wrong answer in detail.

## Optional Week 5 — Capstone & Case Studies
- Build Module 11 end-to-end project.
- Work through `case-studies.md` with the "Google way" answer template.

## Daily habit
- 10 flashcards (from glossary/cheat sheets).
- One "when to use X vs Y" decision drill.
- On weekends, re-run one previous lab without looking at the guide.
