# Module 02 — Exercises

1. Name the four storage classes and their minimum storage durations.
2. Write a lifecycle rule that moves objects to Coldline after 60 days and deletes them after 365 days.
3. Uniform vs fine-grained access — which is recommended and why?
4. How do you enable versioning? What does `numNewerVersions` let you do in lifecycle?
5. Grant a service account read access to a bucket (two ways).
6. CMEK vs CSEK vs Google-managed — when do you pick CMEK?
7. What is the default behavior of object reads when CMEK key is disabled?
8. When would you use Transfer Appliance over Storage Transfer Service?
9. What does `gsutil rsync` do that `cp -r` doesn't?
10. How do you make a single object publicly readable under uniform access? Is it a good idea?
