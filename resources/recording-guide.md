# Video Recording Guide (Udemy course)

Suggested pacing: 26–30 hours of video total, each module 2–3 hours.

## Structure per module
1. **Intro (2–3 min):** what + why it matters on the exam.
2. **Theory (15–20 min):** service architecture, key concepts, decision rules.
3. **Live demo (20–30 min):** run the labs in real time (screen recording).
4. **"Exam focus" (5 min):** the exact exam-style question patterns.
5. **Homework:** link the exercises + code in the module folder.

## Quality checklist per video
- Clear mic, 1080p, code shown at readable zoom.
- No long silences; cut dead time.
- Each lab recorded from a **clean state** (fresh bucket/dataset).
- Cost warnings shown on-screen when creating Composer/Dataproc/streaming.
